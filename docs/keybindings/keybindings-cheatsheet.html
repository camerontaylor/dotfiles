Emacs nav — works in terminal & native fields

⌃a / ⌃eStart / end of line
⌃f / ⌃bForward / back one char
⌃p / ⌃nPrevious / next line
⌃d / ⌃hDelete forward / back
⌃kKill to end of lineown buffer
⌃yYank (paste killed text)
⌃tTranspose characters
⌃k appends on repeat & uses its own buffer, not the clipboard — ⌃k ⌃k from line start cuts a whole line you can ⌃y repeatedly.

Universal Control — split brain

Set once per Mac:
Displays → “Push through the edge…” → OFF
Connect deliberately: Control Center → Display → other Mac
Desktop & Dock → “Displays have separate Spaces” → OFF
Run AeroSpace on both Macs; sync config via dotfiles
Turning off edge-push makes handoff deterministic — no surprise jumps when AeroSpace nudges the cursor or you hit a screen edge.
